# Як працює велика мовна модель — інтерактивна симуляція

Навчальна інтерактивна симуляція українською мовою, що показує повний конвеєр
трансформерної мовної моделі на прикладі одного речення:

1. **Токенізація** — текст ріжеться на токени з номерами словника
2. **Ембедінги** — інтерактивний 3D-простір значень (Three.js, з pinch-zoom на тачі):
   семантичні кластери, найближчі сусіди за косинусною схожістю, «сирі» вектори,
   демо позиційного кодування (синусоїди з оригінального трансформера)
   та шкала масштабу «16 проти 12 288 вимірів у GPT-3»
3. **Механізм уваги** — три перемикані «голови» (зміст / сусіднє слово / якір початку),
   анімовані дуги уваги останнього токена і повна теплова карта
4. **Розподіл імовірностей** — колонка логітів → softmax, регулятори температури й top-k
5. **Семплінг і цикл** — зважений жереб обирає токен, і конвеєр запускається знову;
   жадібний режим показує класичне зациклення greedy-декодування. Кнопка «дописати
   ще речення» дає багатоходовий режим із наочним **вікном контексту**: коли токенів
   стає більше за розмір вікна, найстаріші вибувають — модель їх «забуває»

Наприкінці — **інтерактивний тренажер навчання**: біграмна модель із нульовими
вагами, яку користувач тренує справжнім градієнтним спуском (точний градієнт
крос-ентропії), з живим графіком втрати, регульованою швидкістю навчання
та перевіркою «до/після». Можна задати власне навчальне речення.

## Запуск

Це один самодостатній файл без залежностей (шрифти вбудовані):

```
відкрийте index.html у браузері
```

Підтримуються світла й темна теми (за системним налаштуванням).

Числа згенеровано спрощеною моделлю (~200 слів словника, 16-вимірні вектори),
але кожен крок відповідає реальному конвеєру LLM.

Стан (промпт + температура + top-k) кодується в URL — посиланням можна ділитися.

## Для тих, хто хоче глибше

Наприкінці сторінки — блок посилань на першоджерела (стаття «Attention Is All You
Need», «The Illustrated Transformer», дослідження induction heads від Anthropic,
гайд Hugging Face про температуру/top-k), глосарій-тултіпи для ключових термінів
(логіт, softmax, температура, top-k, косинусна схожість) та індикатор прогресу
проходження станцій.

## Найновіше доповнення

- **Прихований системний промпт** — перемикач у картці вводу додає невидимі
  користувачу токени («Система: будь корисним, ввічливим і стислим асистентом.»)
  з пунктирним стилем; станція уваги показує, що вони так само беруть участь
  у розподілі уваги.
- **Наскрізне трасування токена** — клацніть на будь-який чип у панелі
  контексту чи токенізації: він підсвітиться скрізь — акцентною рамкою в
  контексті, контрастним каркасним кільцем у 3D-просторі значень і рамкою
  навколо всього рядка/стовпця в матриці уваги.
- **RoPE проти класичного додавання позиції** — уточнено різницю між GPT-2/3
  (додавання вектора позиції) і Llama/Mistral (поворот вектора).
- **KV-кеш і FFN-блоки** — розкривні пояснення (`<details>`), що не
  перевантажують сторінку текстом, але доступні охочим копнути глибше.
- **Доступність**: декоративні canvas (шкала вимірів, дуги уваги, графік
  втрати) позначені `aria-hidden`, оскільки їхні дані вже продубльовані
  доступним текстом/таблицею поруч; статистика тренажера — `aria-live`.

## Ще доповнення (за рев'ю живого сайту)

- **Top-p (нуклеус-семплінг)** — повноцінний інтерактивний контрол поруч із
  top-k у станції 4: показує, як «ядро» кандидатів звужується чи
  розширюється залежно від упевненості моделі. Саме so ChatGPT/Claude
  семплять за замовчуванням.
- **LayerNorm і FFN як пам'ять ключ-значення** (Geva et al., 2020) —
  розширено акордеон станції 3.
- **Beam search** — коротке пояснення третього шляху декодування в станції 5.
- **Мультимодальність** — одне речення про те, що зображення й звук
  токенізуються так само.
- **Межа тренажера** тепер візуально виділена (жовтий caveat-бокс), а не
  розчинена в тексті.
- **Список замість 3D** — перемикач у станції 2 для мобільних/тач-екранів:
  текстовий список слів контексту з найближчими сусідами, без потреби
  обертати WebGL-сцену.
