# Як працює велика мовна модель — інтерактивна симуляція

Навчальна інтерактивна симуляція українською мовою, що показує повний конвеєр
трансформерної мовної моделі на прикладі одного речення:

1. **Токенізація** — текст ріжеться на токени з номерами словника
2. **Ембедінги** — інтерактивний 3D-простір значень (Three.js): семантичні кластери,
   обертання, пошук найближчих сусідів за косинусною схожістю + «сирі» вектори
   та шкала масштабу «16 проти 12 288 вимірів»
3. **Механізм уваги** — три перемикані «голови» (зміст / сусіднє слово / якір початку),
   анімовані дуги уваги останнього токена і повна теплова карта
4. **Розподіл імовірностей** — колонка логітів → softmax, регулятори температури й top-k
5. **Семплінг і цикл** — зважений жереб обирає токен, і конвеєр запускається знову

Наприкінці — **інтерактивний тренажер навчання**: біграмна модель із нульовими
вагами, яку користувач тренує справжнім градієнтним спуском (точний градієнт
крос-ентропії), з живим графіком втрати, регульованою швидкістю навчання
та перевіркою «до/після». Можна задати власне навчальне речення.

## Запуск

Це один самодостатній файл без залежностей (шрифти вбудовані):

```
відкрийте index.html у браузері
```

Підтримуються світла й темна теми (за системним налаштуванням).

Числа згенеровано спрощеною моделлю (~200 слів словника, 16-вимірні вектори),
але кожен крок відповідає реальному конвеєру LLM.
